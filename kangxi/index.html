「部首」其实是四样东西

大家把好几样东西都叫「radical / 部首」，其实要分开： "Radical" gets used for four different things that are worth keeping apart:

① 康熙部首（本页）—— 检字用的标准索引，共 214 个。 ② 笔画（单笔）。 ③ 部件 —— 组字的零件，但不一定是部首（亠、ナ）。 ④ 某个课程碰巧当作「radical」教的字（WaniKani 把 七、上、メ 都叫 radical）—— 那是课程的方便，不是字本身的性质，所以不该决定它归到哪一页。 ① Kangxi radicals (this page) — the standard 214-entry lookup index. ② strokes (single strokes). ③ components — assembly parts that aren't necessarily radicals (亠, ナ). ④ whatever a course happens to teach as a "radical" (WaniKani calls 七, 上, メ radicals) — a convenience of the course, not a fact about the glyph, so it no longer decides which page a glyph lives on.
